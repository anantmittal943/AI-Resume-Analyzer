# Security Policy

## Supported versions
The latest main branch is supported.

## Reporting a vulnerability
- Do not open public issues for security vulnerabilities.
- Email report details privately with reproduction steps.
- Include impact, affected endpoints, and possible mitigation.

## Secure development baseline
- No secrets in source control.
- Validate all file uploads and request inputs.
- Rotate credentials and tokens regularly.
- Keep dependencies patched and review CI security reports.
