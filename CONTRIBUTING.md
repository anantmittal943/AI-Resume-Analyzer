# Contributing

## Branch strategy
- Create feature branches from main.
- Keep pull requests focused and small.
- Require passing CI checks before merge.

## Local setup
1. Start backend and frontend using the README instructions.
2. Run quality checks before committing.

## Commit style
- Use imperative commit messages.
- Prefer Conventional Commits format, for example: feat: add resume parser service

## Pull request checklist
- Added or updated tests where relevant.
- Updated documentation for behavior or API changes.
- Verified lint, type checks, tests, and build locally.
